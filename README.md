# The Odin Project

A collection of projects completed as part of The Odin Project curriculum, showcasing web development skills using HTML, CSS, and JavaScript.

## Projects

### Calculator
A fully functional calculator web application with basic arithmetic operations.

- **Technologies**: HTML, CSS, JavaScript
- **Features**: Addition, subtraction, multiplication, division, clear functionality
- **Files**: [`Calculator/index.html`](Calculator/index.html), [`Calculator/style.css`](Calculator/style.css), [`Calculator/script.js`](Calculator/script.js)

### Etch-a-Sketch
An interactive drawing application that allows users to create pixel art on a grid.

- **Technologies**: HTML, CSS, JavaScript
- **Features**: Adjustable grid size, color selection, erase functionality
- **Files**: [`Etch-a-Sketch/index.html`](Etch-a-Sketch/index.html), [`Etch-a-Sketch/style.css`](Etch-a-Sketch/style.css), [`Etch-a-Sketch/script.js`](Etch-a-Sketch/script.js)

### Project Admin Dashboard
A responsive admin dashboard layout with sidebar navigation and project cards.

- **Technologies**: HTML, CSS
- **Features**: Responsive design, sidebar navigation, project cards with icons
- **Files**: [`Project-Admin-Dashboard/index.html`](Project-Admin-Dashboard/index.html), [`Project-Admin-Dashboard/style.css`](Project-Admin-Dashboard/style.css)
- **Assets**: Various SVG icons in [`Project-Admin-Dashboard/assets/`](Project-Admin-Dashboard/assets/)

### Project Landing Page
A modern landing page design for a fictional product or service.

- **Technologies**: HTML, CSS
- **Features**: Hero section, feature highlights, responsive layout
- **Files**: [`Project-Landing-Page/index.html`](Project-Landing-Page/index.html), [`Project-Landing-Page/style.css`](Project-Landing-Page/style.css)

### Project Recipes
A recipe website with multiple recipe pages and a main index.

- **Technologies**: HTML, CSS
- **Features**: Recipe listings, individual recipe pages
- **Files**: [`Project-Recipes/index.html`](Project-Recipes/index.html), [`Project-Recipes/style.css`](Project-Recipes/style.css)
- **Recipes**: [`Project-Recipes/recipes/Cookie_Bars.html`](Project-Recipes/recipes/Cookie_Bars.html), [`Project-Recipes/recipes/Crumb_Bars.html`](Project-Recipes/recipes/Crumb_Bars.html), [`Project-Recipes/recipes/Lemon_Raspberry_Cupcakes.html`](Project-Recipes/recipes/Lemon_Raspberry_Cupcakes.html)

### Rock Paper Scissors
A classic Rock Paper Scissors game implemented in the browser.

- **Technologies**: HTML, CSS, JavaScript
- **Features**: Player vs computer gameplay, score tracking
- **Files**: [`Rock-Paper-Scissors/index.html`](Rock-Paper-Scissors/index.html), [`Rock-Paper-Scissors/style.css`](Rock-Paper-Scissors/style.css), [`Rock-Paper-Scissors/script.js`](Rock-Paper-Scissors/script.js)

## Getting Started

To view any of these projects:

1. Clone or download this repository
2. Navigate to the specific project directory
3. Open the `index.html` file in your web browser

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)

## About The Odin Project

[The Odin Project](https://www.theodinproject.com/) is a free, open-source curriculum for learning web development. This repository contains projects completed as part of their full-stack JavaScript path.
